# 🏥 Doctor Aek DF Helper

Automated Doctor Fee (DF) report generator for Wiset Chai Chan Hospital.

## ✨ Key Features

- **Multi-format Support**: Parse hospital-standard CSV and Excel (.xlsx, .xls) files.
- **Thai Language Fix**: Native support for Thai characters in doctor and patient names.
- **Smart Filtering**:
  - ER: Filter by doctor and shift dates.
  - Ward: Automates 08:00–16:00 same-day admission exclusion.
- **Modern UI**: Professional Graphite Dark Mode theme with smooth transitions.
- **Privacy First**: 100% Client-side processing. No data ever leaves your browser.
- **One-click Copy**: Clean tab-separated output ready for the billing system.

## 🚀 Quick Start

Make sure to install dependencies:

```bash
# npm
npm install

# pnpm
pnpm install

# yarn
yarn install

# bun
bun install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
# npm
npm run dev

# pnpm
pnpm dev

# yarn
yarn dev

# bun
bun run dev
```

## Production

Build the application for production:

```bash
# npm
npm run build

# pnpm
pnpm build

# yarn
yarn build

# bun

```
