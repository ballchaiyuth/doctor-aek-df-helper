how intern doctors in Wiset Hospital work
- วัน ส-อา หรือวันหยุดราชการจะมีคนต้องอยู่เวร
- คนแรกอยู่เวร ER คนนี้จะอยู่ 24 ชม.เลย แบ่งคิดเงินเป็น 8 ชม. 3 รอบ 8:00-16:00, 16:00-24:00, 24:00-8:00 วันถัดไป การคิดเงินจะคิดตามจำนวนกับลักษณะเคส แต่ถ้าเคสน้อยจะคิดเหมารอบละ 1,200
- คนที่สองมาเวร Ward คนนี้จะอยู่ 8 ชม. ตั้งแต่ 8:00-16:00

requirements [การคำนวณ DF เวร ER]
- รับไฟล์ excel/csv/google sheet ข้อมูลเยอะๆเลย ของเดือนนั้นๆ (ข้อดี format ไม่น่าเพี้ยนเลย)
- อ่านไฟล์ เอาแค่ชื่อของตัวเอง เช่น "นายแพทย์สรวิชญ์ สอาดสุด"
- ต้อง filter บางตัวออก (ยากสุด) แต่โชคดีสัสๆ มันเรียงชื่ออยู่ละ (❌ ไม่ต้องทำ)
- 8 ชม. 3 รอบ คิดตามราคารวมเคส หรือเคสน้อยจะคิดเหมารอบละ 1,200

requirements [การคำนวณ DF เวร ward]
- รับไฟล์ excel/csv/google sheet ของเดือนนั้นหมือนกัน
- ward เดี๋ยวเราตัดเวลาเอา 8:00-16:00 ของวันที่เอกอยูาเวรออกด้วย 
- ก็คือจะ query คนมาทั้งหมด และก็ลบด้วยคนที่ admit ใหม่ตอน 8:00-16:00 ออก เพราะมันจะเป็นหน้าที่เวร ER

system design หยาบๆ
- มี 2 หน้าต่ำๆ ER/Ward- (คิดว่าต้องมี) อาจจะมีหน้าอื่นๆให้ดูพวก master data (ชื่อโรคยาวๆ แปลงเป็น รหัสหัตถการ + ชื่อหัตถการ)- (ถ้าอยากต่อยอด) อาจจะดูย้อนหลังได้ว่าเดือนก่อนๆกรอกอะไรไปบ้าง แต่ตอนนี้คิดว่าไม่เอา ไม่อยากมี backend มาเก็บข้อมูล เน้นฟรี55555
- เข้าหน้า initial setup จะให้ลากไฟล์แปะก่อน
- รับไฟล์ + อ่านไฟล์
	- จากนั้นจะได้ข้อมูลมาเล่นละ
	- [ER]
		- ลิสต์รายชื่อหมอ / เลือกรายชื่อหมอ
		- กดเลือกวันที่อยู่เวร ER
		- กด submit จะอ่านรัวๆและดึงข้อมูล
		- ลิสต์ออกมาแยกวันอยู่เวร เช่น 01/02/2026, 05/02/2026 อะไรทำนองนั้น
		- user อ่านคร่าวๆก่อนกด next อันนี้จะหนัก business logic ละ จะแปลพวกรหัสยาวๆ มาเป็นรหัสขอเบิกเงินสั้นๆ เช่น “E110 - Non-insulin-dependent diabetes mellitus” --> “227” เดี๋ยวจะเอาตารางมา จาก excel รหัส หัตถการ + ชื่อหัตถการ/ภาระงาน + ค่า ตอบแทน (master data) มาแปลงเป็น master data ที่ใช้ใน app เราครับ
		- ได้สรุปออกมาเป็น copy able table --> ชื่อ-นามสกุล, HN, วันที่รับ, รหัสหัตถการ
		- หมอเอาไปแปะในเอกสารได้เลย
	- [Ward]		- รับข้อมูลมา แต่ไม่ต้อง filter ชื่อแพทย์ที่นำเข้าระบบ เพราะคนไข้ใน อาจจะรับมาโดยใครก็ได้ แต่คนที่อยู่เวร ward จะไล่ตรวจไปจนคบทุกคน ได้เคสละ 50 บาท แต่ต้องมี logic คัดคนไข้ที่เข้าใหม่ในวันนั้นออก --> logic เดียวที่มีคือ “ต้องคัดคนไข้ที่ admit ใหม่ในวันนั้นตอน 8:00-16:00 ออก เนื่องจากอันนี้แพทย์ ward จะไม่ได้ไปยุ่ง เป็นเคสของแพทย์ ER”
		- ทำเหมือนกัน แต่หลังจาก ลิสต์ออกมาแยกวันอยู่เวร เช่น 01/02/2026, 05/02/2026 ตอนกด next จะ logic ง่ายกว่ากันมากๆ
		- กด next จะนับจำนวนยอดมาไล่ทำเป็นลิสต์ยาวๆ --> ชื่อ-นามสกุล, HN, วันที่รับ, รหัสหัตถการ เฉยๆ แต่จะ auto ใส่ไปเป็น “213” หมดเลยครับ และพอ paste ระบบจะไปคำนวณให้เอง เช่นช่อง F18 เรา paste ลงไปว่า “213” ช่อง F19 ก็จะไปคำนวณๆออกมาให้ครับ
