== WHAT IS THIS PROJECT ==
doctor-aek-df-helper is a Nuxt 4 web application that automates Doctor Fee (DF) report generation for Dr. Sorawit (Aek), an intern doctor at Wiset Chai Chan Hospital.

== WHAT HAS BEEN DONE ==
1.  Project initialized with Nuxt 4, Tailwind v4, and PrimeVue.
2.  CSV/Excel parsing logic with Thai encoding support.
3.  ER Logic: Grouping by 3 shifts (08-16, 16-24, 24-08).
4.  Ward Logic: Automation of 08:00-16:00 same-day admission exclusion.
5.  **Smart Copy (ER)**: Intelligent clipboard function that consolidates low-fee shifts into claim text while preserving raw data for high-fee shifts.
6.  **Executive Dashboard**: Stat cards for Total Patients, Working Days, and Estimated Real Income.
7.  **Smart Revenue**: Calculation of Grand Total including 1,200 THB minimums per ER shift.
8.  **Ward Daily Totals**: Integrated revenue summaries after each day's rounding list.
9.  **Excel v9 & 1899 Fix**: Upgraded to read-excel-file v9 and resolved historical timezone shift (6:42h) using UTC extraction.
10. **Clean Architecture**: Refactored calculation logic for daily-based shift evaluation.
11. **Strictly Typed & Linted**: 100% pass on `pnpm lint` after resolving all `any` and unused variable warnings.

== CRITICAL BUSINESS RULES ==
- ER: Filter by doctor + shift. If shift total < 1,200, use flat rate.
- Ward: Get all for shift date, exclude those admitted 08-16 on the same day.
- Output: Copyable tab-separated text for hospital Excel system.
