Date: 2026-04-07

== WHAT IS THIS PROJECT ==
doctor-aek-df-helper is a Nuxt 4 web application that automates Doctor Fee (DF) report generation for Dr. Sorawit (Aek), an intern doctor at Wiset Chai Chan Hospital. The app parses hospital CSV/Excel exports, applies ER/Ward business logic, maps ICD-10 codes to billing codes, and produces copyable report tables for the doctor to paste into the hospital billing system.

== TECH STACK ==
- Framework: Nuxt 4.4.2 (Vue 3.5.32)
- Styling: Tailwind CSS 4.2.2 via @tailwindcss/vite plugin (CSS-first config, NO tailwind.config.ts)
- UI Components: PrimeVue 4.5.4 (Aura theme via @primeuix/themes)
- Design System: Graphite Dark Mode (Custom theme using Tailwind v4 @layer base)
- Data Processing: csv-parse 6.2.1 and read-excel-file 8.0.3
- Icons: FontAwesome SVGs via CSS Masking (mask-image)
- Date Logic: date-fns 4.1.0
- Build: Vite 7.3.2
- Package Manager: pnpm
- Deployment Target: Vercel (Static Site, No Backend — all data stays in client browser)

== CRITICAL BUSINESS RULES ==
- ER: Filter patients by selected doctor name + shift dates, map ICD-10 to billing codes from master-mapping.json
- Ward: Get ALL patients for shift dates, EXCLUDE those admitted on the same day between 08:00:00 and 15:59:59 (those belong to ER doctor), auto-assign billing code "213"
- Output format: [Patient Name, HN, Admit Date, Billing Code] as copyable tab-separated text
